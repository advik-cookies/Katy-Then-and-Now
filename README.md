# Katy: Then and Now – Custom Components

## Overview
Destination Imagination Team "5 to Infinity" developed the “Katy: Then and Now” web project to highlight community growth and preserve old cultural norms through modern web design.
While the main site was built in Google Sites, this repository contains the custom code used to enhance the site's functionality and design through embedded HTML/CSS components.
### Link to Live Website
[Link to Katy: Then and Now Live Website](https://sites.google.com/view/katythenandnow/)

## Custom Components Included

This repository includes code for:

- Before-and-after comparison containers
- Structured image display containers
- Timeline sections for historical progression
- Carousel containers for interactive browsing
- Embedded maps with interactive elements
- Animated engagement popup (animal icon for user interaction)

These components were created to extend the design flexibility of Google Sites and improve user engagement.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Embedded code integration within Google Sites

## Purpose of This Repository

The purpose of this repository is to:
- Showcase custom front-end development work
- Demonstrate the ability to enhance no-code platforms with custom code
- Provide reusable container components for similar projects
- Document the structured layout system used in the project

## Project Focus

This project emphasizes:
- Clean layout structuring
- Visual storytelling through historical comparison
- Interactive engagement features
- Responsive and organized container systems
